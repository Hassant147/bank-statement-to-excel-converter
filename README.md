## 📌 Overview

**[StatementToExcel](https://statementtoexcel.site)** is an open-source client-side engine designed to convert PDF bank and credit card statements into structured **Microsoft Excel (.xlsx)**, **QuickBooks Online (.qbo / .csv)**, and **Xero (.csv)** spreadsheets without sending confidential financial records over the internet.

Traditional PDF converters (such as DocuClipper, ProperSoft, or MoneyThumb) transmit your unencrypted PDF statements to third-party cloud servers for processing. This presents significant privacy risks under **GDPR Art. 25**, **GLBA (Gramm-Leach-Bliley Act)**, and CPA professional ethical confidentiality rules.

**StatementToExcel runs 100% locally in browser RAM using compiled WebAssembly.** Your account numbers, balances, payee names, and transaction history never leave your local machine.

---

## 🌟 Key Capabilities

* **🔒 100% Zero-Knowledge Guarantee:** PDF processing, 2D spatial text clustering, table reconstruction, and Excel rendering occur entirely within your client's web browser memory.
* **📐 Standard 5-Column Financial Layout:** Automatically normalizes messy statement layouts into strict double-entry ready format:
  1. `Date` (Standardized `YYYY-MM-DD` or locale preference)
  2. `Description / Payee` (Normalized without internal bank noise)
  3. `Withdrawals / Debits` (Positive floating point numbers)
  4. `Deposits / Credits` (Positive floating point numbers)
  5. `Running Balance` (Computed and verified)
* **🌍 Multi-Currency & Date Disambiguation:**
  * Auto-detects and formats US (`MM/DD/YYYY`), UK/Europe (`DD/MM/YYYY`), and German/Swiss (`DD.MM.YYYY`) statement dates.
  * Native multi-currency symbol support (`$`, `€`, `£`, `CAD`, `AUD`, `CHF`).
* **⚡ Accounting Software Direct Export:**
  * **Microsoft Excel (.xlsx):** Auto-fitted column widths, numeric cell typing (no text-formatted numbers), formatted header row.
  * **QuickBooks Online (.qbo & CSV):** Pre-formatted 3-column and 4-column bank feeds for 1-click import into QBO, Xero, and Sage.
* **🛡️ Password-Protected Statements:** Decrypts locked monthly PDF statements securely inside browser RAM using client-side WebCrypto before parsing.

## ⚙️ How It Works (Client-Side Architecture)

```
┌────────────────────────────────────────────────────────┐
│                   CLIENT WEB BROWSER                   │
│                                                        │
│  [ Bank Statement PDF ]                                │
│           │                                            │
│           ▼                                            │
│  [ WebAssembly PDF Parser (Mozilla PDF.js Engine) ]    │
│           │                                            │
│           ▼                                            │
│  [ 2D Spatial Layout & Line Item Clusterer ]          │
│           │                                            │
│           ▼                                            │
│  [ Multi-Locale Date & Currency Regex Disambiguator ]  │
│           │                                            │
│           ▼                                            │
│  [ Mathematical Debit/Credit Balance Verification ]    │
│           │                                            │
│           ▼                                            │
│  [ In-Memory SheetJS (XLSX) / CSV / QBO Serializer ]   │
│           │                                            │
│           ▼                                            │
│  [ 1-Click Local File Download (.xlsx / .qbo) ]        │
└────────────────────────────────────────────────────────┘
```

> **Zero Network Requests:** Open your browser's Network tab (`F12`). When you drag and drop a 50-page PDF, notice that **zero payload bytes are transmitted to any backend**. Everything runs inside local client JavaScript/WebAssembly memory threads.

## 📖 Quickstart Guide

### Option 1: Use the Web Application (No Installation Required)
Simply navigate to the production web interface:
👉 **[https://statementtoexcel.site/convert](https://statementtoexcel.site/convert)**

1. Drag and drop your bank statement PDF.
2. Select your export format: **Excel (.xlsx)**, **QuickBooks (.qbo)**, or **CSV**.
3. Choose your date format (Auto-detect, `MM/DD/YYYY`, or `DD/MM/YYYY`).
4. Review transactions in the live interactive table preview.
5. Click **Download Spreadsheet**.

### Option 2: Programmatic Usage (Client-Side Node / TypeScript)
Clone the repository:
```bash
git clone https://github.com/Hassant147/bank-statement-to-excel-converter.git
cd bank-statement-to-excel-converter
npm install
npm run build
```
